CARPETA: backend/app/api/v1/endpoints
=====================================

¿QUÉ ES ESTA CARPETA?
Aquí viven los "endpoints" concretos: la función de cada ruta de la API.
Cada archivo agrupa rutas de un tema (salud, usuarios, etc.).

ARCHIVOS:

1. health.py
   - Endpoint de "salud" del sistema: GET /health
   - Devuelve el estado de la API y de la base de datos.
   - Ejecuta la consulta "SELECT 1" contra la base de datos:
       • Si funciona  -> database: "connected"
       • Si falla     -> database: "error"
   - Usa Depends(get_db) para obtener la sesión de la base de datos
     (SQLAlchemy asíncrono).

   IDEAS PARA EL EXAMEN:
   • Un "healthcheck" verifica que el servidor está vivo y la BD conectada.
   • Depends() es la forma de FastAPI de inyectar dependencias (aquí, la sesión).

2. users.py
   - Archivo PLANIFICADO (aún vacío).
   - Servirá para las rutas de usuarios: GET /users, GET /users/{id}, etc.
   - Quedó comentado en el router principal: se activará cuando se implemente.

3. __init__.py
   - Marca la carpeta como paquete de Python. Está vacío.

CÓMO SE CONECTA CON EL RESTO:
   api_router (v1/router.py)  ->  include_router(health.router, prefix="/health")
   URL final del health:  /api/v1/health/    (prefijo /api/v1 + /health)
